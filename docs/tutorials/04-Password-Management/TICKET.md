# Set Up LastPass and Manage Your Passwords

## Objective

Read the [Complete Guide to Password Management](https://github.com/easyscale-academy/learn_easyscale_academy_essentials-project/tree/04-Password-Management/), set up LastPass as your password manager, and migrate your important account passwords into LastPass.

## How-to Guide

1. Sign up for LastPass with your Gmail account — when creating your master password, use the "passphrase method" described in the guide
2. Hand-write or print your recovery code and store it somewhere safe
3. Install the browser extension and the mobile app
4. Log into Gmail, Outlook, and GitHub one by one — use LastPass to generate a random password for each and update accordingly
5. Test that autofill is working properly

## Checklist

- [ ] **Sign up for LastPass** — Register with your Gmail account and create a strong master password
- [ ] **Save your recovery code** — Hand-write or print it and keep it in a safe place (this is your only lifeline if you ever lose your master password)
- [ ] **Install the tools** — Browser extension + mobile app
- [ ] **Migrate your Gmail password** — Replace it with a randomly generated password from LastPass
- [ ] **Migrate your Outlook password** — Replace it with a randomly generated password from LastPass
- [ ] **Migrate your GitHub password** — Replace it with a randomly generated password from LastPass
- [ ] **Add other accounts** — School email and any other accounts you use regularly (keeping existing passwords is fine for these)
- [ ] **Verify autofill** — Visit the Gmail/GitHub login pages and confirm LastPass fills in your credentials automatically
