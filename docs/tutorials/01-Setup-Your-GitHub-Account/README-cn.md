## 🎯 为什么要学这个？

想象一下这个场景：你精心准备了简历，写上了"熟悉 Python 数据分析"、"参与过机器学习项目"。但招聘官看到后的第一反应是什么？

**"证据呢？"**

在 2026 年的求职市场，光说自己会什么已经不够了——每个人都会用 AI 美化简历，每份简历看起来都很厉害。招聘官（甚至是 AI 筛选系统）需要的是**可验证的证据**。

而 GitHub，就是你展示证据的地方。

它就像你的在线作品集：你做过的项目、写过的代码、解决过的问题，全都摆在那里，任何人都可以查看和验证。当你的简历上有一个 GitHub 链接，招聘官可以直接点进去看你的真实能力——这比任何华丽的自我描述都有说服力。

简单来说：**没有 GitHub = 你说的话没有证据支撑。**

## 📖 GitHub 能为你做什么？

**专业作品集：** 你的每一个项目都会有一个独立的"仓库"（[Repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/about-repositories)），里面存放代码、文档、说明。招聘官可以直接查看你的工作成果。

**提高 AI 筛选通过率：** 现在很多公司用 AI 系统筛选简历。这些 AI 会搜索你简历上提到的项目是否真实存在。简历上有 GitHub 链接，AI 系统会认为你更可信，通过率自然更高。

**职业发展的基础设施：** 版本管理让你追踪项目的每一次更新，比网盘专业得多；项目管理功能帮你用看板管理任务；未来工作中，你几乎一定会用到 GitHub 和同事协作。

> 💡 **重要提醒：** GitHub 不只是程序员的工具。项目文档、技术博客、数据文件整理——任何需要版本控制的工作都可以用它。在美国科技行业，GitHub 已经是职场人士的标配。

## 📖 注册前的准备

在注册之前，请确保你有一个**长期可用的个人邮箱**（推荐 Gmail）。

⚠️ **不要用学校邮箱！** 学校邮箱会在毕业后失效，届时你可能会失去对 GitHub 账号的访问权限。

如果你还没有 Gmail，请先去 [Gmail 官网](https://gmail.com/) 注册一个。

## 📖 注册 GitHub 账号

### 打开注册页面

访问 [GitHub 官网](https://github.com/)。在页面右上角，你会看到一个绿色的 **Sign up** 按钮，点击它进入注册流程。

### 填写注册信息

注册页面会依次询问三个关键信息：

**邮箱地址（Email）：** 输入你的 Gmail 邮箱。这是登录 GitHub 的凭证，属于私密信息，不会公开显示。

**密码（Password）：** 设置一个强密码，至少 15 个字符，包含大小写字母、数字和符号。示例格式：`` MyGitHub@2026!Secure ``。请务必将密码保存到你的密码管理器中。

**用户名（Username）：** 这是你在 GitHub 上的公开身份，全球唯一，会出现在你的个人主页 URL 中，格式是 `` github.com/你的用户名 ``。

### 选择用户名（非常重要！）

你的用户名会成为你的职业名片——放在简历上、LinkedIn 上、邮件签名里。请认真选择。

**好的用户名示例：** `` john-chen ``（简短、清晰、专业）、`` alice-li ``（名字拼音组合）、`` david-wang ``（易记、易读）

**避免这些做法：** `` john123456789 `` 太长显得不专业；`` CodingNinja2023 `` 太随意不适合求职；`` user_2024_temp `` 看起来像临时账号；`` xjasdjkasjdkl `` 无法记忆非常不专业。

**建议：** 用你的真实名字（拼音或英文），保持在 15 个字符以内。

### 完成验证

填写完信息后，GitHub 会向你的邮箱发送一封验证邮件。打开邮件，点击验证链接，返回 GitHub，你的账号就激活了。

## 📖 理解两个核心概念

### 邮箱 vs 用户名

很多新手会混淆这两个东西，但它们完全不同。**邮箱**是你的登录凭证，是私密的，只有你知道。**用户名**是你的公开身份，全世界都能看到，会出现在你的 URL 里。

举个例子：如果你的用户名是 `` alice-wang ``，那么你的 GitHub 个人主页就是 `` github.com/alice-wang ``，这个 URL 可以直接放在简历上。

### 仓库（Repository）

把"仓库"想象成一个智能文件夹。每个项目都有一个对应的仓库，仓库里存放项目的所有代码、文档、文件。仓库可以是公开的（全世界可见）或私密的（只有你能看到）。

**在求职中，公开仓库就是你最有力的证据。** 招聘官可以直接查看你的代码和项目。

仓库命名示例：`` data-analysis-dashboard ``（清晰描述项目内容）、`` stock-market-predictor ``（通俗易懂）、`` real-time-analytics-platform ``（描述项目功能）

## 📖 完善个人资料

注册完成后，花 2 分钟完善你的个人资料，让账号看起来更专业。

### 进入设置页面

点击页面右上角的头像图标（一个圆形的默认头像），在下拉菜单中点击 **[Settings](https://github.com/settings/profile)**。

### 需要设置的内容

**头像（Profile picture）：** 上传一张专业的照片或清晰的头像，避免使用卡通图片或模糊的照片。

**个人简介（Bio）：** 用一句话介绍自己。示例：`` Data Engineer | AI Enthusiast | Based in NYC `` 或 `` CS Student at UCLA | Python & Machine Learning ``

**地理位置（Location）：** 填写你所在的城市，如 `` San Francisco, CA ``

**个人网站（Website）：** 如果你有技术博客或个人网站，可以添加链接。这一项是可选的。

## 👨‍🏫 导师寄语：GitHub 不只是工具，是你的职业身份

完成了 GitHub 账号注册，你可能会想："这不就是注册了一个网站账号吗？有什么特别的？"

让我和你分享一个更深层的认识：**在数字时代，你的 GitHub 账号就是你的职业身份证。**

### 从"我说我会"到"我证明我会"

传统求职是这样的：你在简历上写"精通 Python"，招聘官选择相信或不相信你。这是一种基于信任的模式。

但现在，招聘官可以直接去你的 GitHub 看：你写过什么代码？你的代码风格如何？你解决过什么问题？你能和别人协作吗？

这是一种基于证据的模式。

当你开始认真经营你的 GitHub，你就是在为自己建立一份**可验证的职业履历**。每一次 Commit，每一个 Pull Request，每一份文档，都是你能力的证据。

### 你的用户名，是你的职业品牌

今天你选择的用户名，可能会跟随你整个职业生涯。它会出现在你的简历上、LinkedIn 上、技术文章的署名里、开源项目的贡献者名单中。

我见过太多人在工作几年后后悔当初随便起的用户名——要么太幼稚，要么太长记不住，要么跟真实身份毫无关联。

所以，请像对待你的真实姓名一样认真对待你的 GitHub 用户名。它是你在技术世界里的"名字"。

### 从今天开始的习惯

我想给你一个建议：**把 GitHub 当作你的职业日记本。**

不需要等到做出惊天动地的大项目才往上放东西。学习笔记、小工具、课程作业、练习代码——只要是你自己写的、能展示你成长轨迹的内容，都可以放上去。

重要的不是每一次提交都很完美，而是让招聘官看到：这是一个持续学习、持续成长的人。

**从今天起，你的每一次努力，都将有迹可循。**
