# EasyScale Academy Essentials

The prerequisite foundation for all EasyScale Academy courses.

This module introduces the two core tools you'll use throughout your learning journey:

- **GitHub** — Manage your learning artifacts with version control. Track your notes, assignments, and project deliverables in a structured, professional way.
- **GitHub Projects** — Stay on top of your progress with a Kanban-style task board. See what's assigned, what's in progress, and what's complete at a glance. Your mentor can also monitor your progress and provide feedback directly on task cards.

This is not a comprehensive tutorial on GitHub or GitHub Projects. Instead, it focuses specifically on how to use these tools to navigate EasyScale Academy courses — keeping your work organized, your progress visible, and your communication with mentors seamless.
